# Project €1

The world's most honest business.

Give €1.
Receive nothing.

## About

Project €1 is an open-source internet experiment exploring whether a simple, humorous idea can create community participation.
People donate a simple €1 to me and recieve absolutley nothing in return. They fund my ridiculous antics all to see how far crowdfunding can truly go. 

The project tests whether a simple humorous concept can create engagement and demonstrate how small individual actions can combine into a larger movement.

The experiment explores questions like:

Can a simple idea bring people together online?
What makes internet projects spread?
Can transparency and humour create community?

Rather than selling a product, Project €1 intentionally challenges traditional online business models by creating a transparent and self-aware digital experiment.
